# 金额分格输入组件能力说明

- 组件入口：`src/components/money-grid-input/MoneyGridInput.vue`，由凭证分录表格的借方金额、贷方金额单元格使用。
- 输入能力：支持普通金额输入、正负数、小数、键盘方向导航、Tab/Enter 提交并切换单元格；支持输入包含 `+ - * /` 的表达式后进入金额计算弹窗。
- 实时同步：编辑状态下监听输入框 `input` 事件；当草稿内容是普通数字、正负数或小数时，实时触发 `update:modelValue` 和 `upper-change`，让父级分录行金额、科目余额、借贷合计等联动内容在输入过程中立即刷新；包含运算符的表达式仍等提交后进入金额计算弹窗。
- 分格展示：非编辑状态按亿、千、百、十、万、千、百、十、元、角、分分格展示金额数字；金额格内数字加粗，提升可读性。
- 编辑体验：进入编辑状态时不再显示额外浮层，直接聚焦当前金额格内输入框；输入框内金额字号放大为 22px、加粗、右对齐，用户在当前格内即可看清录入金额。
- 大写金额：当 `showUpperText` 开启且存在金额大写时，在金额格下方展示大写金额；默认仍通过单元格 title 辅助查看。
- 数值限制：最大金额限制为 ±999,999,999.99，提交时自动保留两位小数并同步大写金额。
- 事件输出：通过 `update:modelValue`、`change`、`upper-change`、`navigate` 向父组件同步金额、金额大写和键盘导航方向；`change` 仍在提交时触发，用于需要提交态的业务逻辑。
