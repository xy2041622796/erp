# 收入合同页面 skill

## 页面入口
- 路径：`apps/web-ele/src/views/erp/contract/income`
- 页面文件：`index.vue`
- 表单文件：`modules/form.vue`
- 客户详情弹窗：`modules/customer-detail-modal.vue`
- 项目详情弹窗：复用 `../project/modules/form.vue` 的详情弹窗
- 表单配置：`data.ts`

## 页面能力
- 支持新增、编辑、查看收入合同。
- 列表中的客户名称点击后改为弹出客户信息弹窗，不再跳转客户详情路由。
- 列表中的项目名称点击后改为弹出项目详情弹窗，交互方式与客户超链接一致。
- 客户信息弹窗直接复用 `src/views/erp/client/customer/modules/form.vue` 的展示内容，并通过 `getCustomer` 加载当前客户数据，不依赖 `crm/*` 接口。
- 项目详情弹窗直接连接 `src/views/erp/contract/project/modules/form.vue`，并通过传入 `type=detail` + `rowid` 进入只读详情态。
- 收入合同里打开客户信息弹窗时，会给客户表单传 `readonly`，因此该处只读展示、不可编辑；客户信息页原入口不传该参数，仍保持可编辑。
- 收入合同“详情”与“编辑”共用同一表单组件，但详情态会切为只读展示，保存/上传/删除等编辑动作会隐藏。
- 支持维护合同产品与收款计划。
- 支持新增后自动生成首期收入结算单。
- 产品选择弹窗已支持多选；收入合同新增/编辑时可一次勾选多个产品批量带入，已存在产品会自动跳过。
- 产品清单金额口径已对齐销售订单：用户输入“含税单价”，同时展示未税单价、未税金额、税额、含税金额；保存时仍向后端落未税单价 `unit_price` 与未税金额 `amount`，无需调整子表结构。
- 列表与详情中的合同金额标题已统一为“未税金额 / 含税金额”，避免与产品清单口径不一致。
- 新增收入合同时，签订日期与交付日期会自动默认填入当天日期。
- 收款账户下拉值已改为使用结算账户主键 `rowid`，修复下拉可见但无法选中的问题。
- 收入合同中的“选择来源销售订单”弹窗里，“下单时间”统一按 `YYYY-MM-DD` 展示，只显示日期，不显示时分秒。

## 附件规则
- 附件真实数据来源为 `file_FJ`，不再依赖旧的 `attachment / Upload` 表单字段。
- 当前页面附件 `owner_type = 收入合同`。
- 编辑/详情打开时，需要按 `pid = 合同rowid` 且 `owner_type = 收入合同` 查询 `file_FJ` 回显。
- 新增合同时，附件先放前端草稿列表，主表保存成功后再批量落库到 `file_FJ`。
- 已存在合同上传附件时，直接写入 `file_FJ`。
- 附件区位于表单底部，展示列：文件名、文件大小、文件类型、操作。

## 使用到的数据与接口
- 主表接口：`#/api/erp/contract/contract`
- 客户接口：`#/api/erp/customer`
- 附件接口：`#/api/erp/customer`
- 附件表：`file_FJ`
