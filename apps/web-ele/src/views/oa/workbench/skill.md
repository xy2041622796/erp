# 协同云工作台 skill

## 页面能力
- 提供协同云工作台首页，布局贴近参考图，包含顶部快捷按钮、导航胶囊、我的待办、项目概览、合同概览、快捷入口。
- 待办列表支持展示审批分类、处理人、时间和强调动作按钮。
- 项目概览支持展示项目编码、负责人、进度条和风险提示。
- 合同概览支持展示合同编码、金额、单位、到期时间和执行状态。
- 页面内所有卡片均可通过路由跳转到 OA 项目、合同或工作台相关页面。

## 页面入口
- 视图文件：`src/views/oa/workbench/index.vue`
- 典型路由：`/oa/workbench`

## 使用到的数据
- 当前使用页面内静态演示数据：
  - 顶部导航 `topLinks`
  - 快捷按钮 `quickActions`
  - 待办列表 `todoItems`
  - 项目概览 `projectItems`
  - 合同概览 `contractItems`

## 依赖与接口
- UI：`@vben/common-ui`、`element-plus`
- 路由：`vue-router`
- 当前未接后端 API；后续可替换为 OA 待办聚合接口、项目看板接口、合同台账接口。
