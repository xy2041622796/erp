# 凭证会计科目选择组件能力说明

- 组件入口：`src/views/finance/cwhs/Voucher/modules/VoucherSubjectPicker.vue`，由凭证分录表格 `VoucherEntryTable.vue` 使用。
- 页面能力：在凭证分录中选择会计科目，支持聚焦自动展开、关键字过滤、科目分类页签、末级科目选择、新增科目入口和键盘导航。
- 数据来源：接收父组件传入的 `modelValue`、`options`、`loading`、`remoteMethod`，通过 `update:modelValue`、`focus`、`blur`、`select` 与父组件交互。
- 展示布局：触发器使用 `voucher-subject-trigger` 容器，单元格内不展示“科目”前置标签，整列空间用于展示科目编码/名称信息。
- 长内容处理：科目信息输入框固定 56px 高度，不使用 autosize，不撑开表格行；内容过长时在输入框内部纵向滚动展示完整信息。
- 余额避让：textarea 底部 padding 预留 24px，给凭证分录表格中的余额提示展示在科目信息下方，避免文字与余额重叠。
- 弹层能力：下拉面板支持全部、资产、负债、权益、成本、损益页签；非末级科目不可选，搜索上级科目时展开展示下级末级科目。
- 性能优化：搜索上级科目展开下级时，先按 `parent_subject_number` 构建父子索引，再按匹配节点向下遍历；关闭状态下不构建展示列表；不在每个单元格组件中复制完整科目列表，只精准缓存已选科目。
- 动态渲染：科目下拉列表改为虚拟滚动，`displayOptions` 保留完整匹配结果，但 DOM 只渲染当前可视区加缓冲区的数据；通过顶部/底部占位保持滚动高度，避免大账套一次性渲染上千个科目节点导致卡死。
- 键盘体验：上下方向键移动 activeIndex 时会自动滚动到当前项，切换分类或输入搜索词时重置虚拟滚动位置。
- 小屏适配：弹层根据视口动态计算上/下展开方向与列表高度，限制最大高度并避免溢出；小屏下压缩行高、间距和余额列宽，减少遮挡金额录入区。
- 查看态兼容：当父组件传入 `disabled=true` 时，科目输入框 placeholder 为空，避免查看凭证时空科目误显示“请输入科目编码/名称”；当前查看态主要由 `VoucherEntryTable` 直接渲染纯文本科目。
