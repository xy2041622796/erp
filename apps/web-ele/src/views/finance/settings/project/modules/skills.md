# 科目新增弹窗 skill

## 入口
- 页面文件：`src/views/erp/finance/settings/project/modules/form.vue`
- 使用场景：财务设置 -> 科目设置 -> 新增科目 / 新增下级科目
- 复用场景：新增凭证里的科目选择器中点击“新增科目”后，也会复用这个弹窗

## 本次能力说明
- 在“首次新增子级科目”场景下，检查上级科目是否已有凭证明细。
- 若上级科目已有凭证，则弹出业务确认提示：
  - `亲，上级科目已存凭证，保存后新增科目将替代凭证中的上级科目，您要继续吗？`
- 若上级科目没有凭证，则本次不弹该提示，继续后续保存流程。
- 业务确认提示框单独指定固定高层级，避免在凭证页、科目选择器下拉、正式环境多弹层叠加时被遮挡或压在下层。

## 关联数据与接口
- 查询全部科目：`getAllSubjectList`
- 查询上级科目：`getSubjectByNumber`
- 统计凭证明细：`countVoucherDetailsByAccountCode`
- 新增科目：`createSubject`
- 更新科目：`updateSubject`
- 转移凭证明细：`moveVoucherDetailsToSubject`

## 当前实现边界
- 本次只改了“首次新增子级”的确认提示文案、触发条件与弹层层级。
- 仅当上级科目存在凭证明细时弹窗；无凭证时不弹此提示。
- 当前显式层级：
  - 科目弹窗 Select 下拉：`10050`
  - 业务确认遮罩：`11999`
  - 业务确认框体：`12000`
- 未改动发生额、余额迁移逻辑。
