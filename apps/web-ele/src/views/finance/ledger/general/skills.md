# 总账（General Ledger）页面

## 能力
- 按查询期间生成总账数据，展示同一科目下每个月的期初余额、本期合计、本年累计。
- 多月查询时，结果以科目作为一级归集，不再以月份作为一级分组，保证同一类科目展示在一起。
- 不展示凭证明细流水。
- 不展示凭证号列。
- 不展示摘要列。
- 表格列完整展示为：科目编码、科目名称、日期、期间、借方金额、贷方金额、方向、余额。
- 顶级科目行按下级科目汇总后的金额展示，期间列标记为“期初余额”。
- 列宽按总账汇总口径压缩并启用表格自适应，避免无关列占位和横向挤压。
- 每个查询月份都会在该科目下连续展示三行；“日期”列显示 `YYYY年M月`，“期间”列显示 `期初余额`、`本期合计`、`本年累计`。
- 查询开始月份的期初余额会包含年初到该月月初之前的累计发生额，保证非 1 月开始查询时余额连续正确。
- 顶部查询区支持月份区间选择；科目编码/名称关键字过滤与“只展示顶级”收纳在“筛选条件”按钮内。
- 支持总账打印、导出；导出不包含凭证号和摘要列，沿用页面当前表格数据。

## 入口
- 前端页面：`src/views/finance/ledger/general/index.vue`
- 组件名：`FinanceGeneralLedger`
- 列配置：`src/views/finance/ledger/general/data.ts`
- 数据接口封装：`src/api/erp/finance/ledger/general.ts`

## 数据来源/接口
- 会计科目：`getAllSubjectList`（Bil_Subject_Info）
- 科目期初/年初余额：`getSubjectOpeningList`（Bil_Subject_Opening）
- 凭证主表与明细：`getVoucherPage` + `getVoucherDetails`（Bil_Voucher_Main / Bil_Voucher_Detail）

## 计算口径（当前实现）
- 年初余额：优先取 `Bil_Subject_Opening.year_beginning_balance`，若为空则回退 `beginning_balance`。
- 查询凭证范围：从查询开始月份所在年份年初，到查询结束月份月末。
- 科目归集：先取全部科目用于父级汇总，关键字仅影响最终展示集合；命中子科目时保留其父级科目。
- 父级/顶级科目：子科目的期初和发生额会向已有父级科目汇总；顶级科目展示的是本类科目的汇总金额。
- 月度期初余额：年初余额 + 年初至该月月初之前的净发生额。
- 本期合计：当前月份借/贷发生额与当前月份期末余额。
- 本年累计：年初至当前月份月末借/贷累计与年初至当前月份月末余额。
- 科目汇总行：展示该科目查询期间最后月份的借贷发生、期末方向和余额；下级 children 承载逐月汇总。
- 展示过滤：只要科目存在年初余额或查询期间内发生额，即生成该科目节点；查询区间内无发生的月份也保留期初、本月、本年行，保证月份连续。

## 回归测试约定
- 选择 1-3 月查询时，一级行应为科目编码/科目名称，不应再出现月份一级分组。
- 同一科目的 1 月、2 月、3 月内容应连续出现在该科目的 children 中。
- 每个月只出现期初余额、本期合计、本年累计，不出现凭证明细流水。
- 页面和导出均不应出现凭证号列、摘要列。
- 页面表格应完整展示 8 列：科目编码、科目名称、日期、期间、借方金额、贷方金额、方向、余额。
- 从非 1 月开始查询时，首月期初余额应包含年初到首月月初之前的累计发生额。
