# 多栏账页面

## 页面能力
- 按会计期间和会计科目查询多栏账。
- 顶部查询区平铺展示，不使用下拉筛选面板：第一个控件为会计期间，后续为科目下拉、显示范围、明细栏余额、查询/重置。
- 科目使用可搜索下拉选择，支持按科目编码或名称过滤。
- 选择会计期间、科目、显示范围或明细栏余额后会自动触发查询，同时仍保留查询按钮。
- 支持“最明细科目”和“下级科目”。
- 支持显示明细栏余额。
- 根据所选科目动态展开下级科目列，形成多栏账表格。
- 展示凭证日期、凭证字号、摘要、借方、贷方、方向、余额。
- 金额列无值或零值统一展示为 `0.0`。
- 自动生成本期合计、本年累计、期末余额行。
- 支持打印和导出 CSV。
- 表格区域支持鼠标滚轮横向滚动，便于查看右侧动态多栏列。

## 页面入口
- 文件位置：`src/views/finance/ledger/multi-column/index.vue`
- 后续需要挂菜单时，可放在序时账之后。

## 使用的数据或接口
- `src/api/erp/finance/ledger/multi-column.ts`
- 科目数据来源：`getAllSubjectList`，对应 `Bil_Subject_Info`。
- 凭证数据来源：`getVoucherPage`、`getVoucherDetails`，对应凭证主表和凭证明细。
- 横向滚轮能力使用：`src/hooks/use-horizontal-wheel-scroll.ts`。

## 交互说明
- 默认科目为 `5602 管理费用`，适配管理费用多栏账场景。
- 顶部查询控件顺序固定为：会计期间、科目下拉、显示范围、显示明细栏余额、查询、重置。
- 不再使用“筛选”悬浮/下拉面板。
- 会计期间、科目下拉、显示范围、显示明细栏余额发生变化后自动查询。
- 多栏列按科目编码匹配凭证明细，凭证明细科目编码以多栏科目编码开头即归入该栏。
- 余额方向按所选科目的 `balance_direction` 判断，默认借方方向。
- 默认选中“下级科目”。
- “显示明细栏余额”复选框控制表格右侧“明细栏余额”列显示或隐藏。
- 页面内不直接维护横向滚动 DOM 监听，统一通过 `useHorizontalWheelScroll(tableWheelRef)` 复用。

## 主题说明
- 页面使用 Element Plus / lmbill 现有主题变量。
- 主色、表头、汇总行均复用 `var(--el-color-primary)`、`var(--el-bg-color)`、`var(--el-border-color-light)` 等变量。
