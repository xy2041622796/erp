# 科目余额表页面

## 能力
- 按月份生成科目余额表。
- 页面顶部查询区已整体重构为完整工具栏卡片，不再是零散控件平铺；期间、科目范围、搜索、显示选项、打印导出分区更清晰。
- 顶部左侧显示“查询期间”信息块：月份选择器 + 当前期间标签，统一使用 `YYYY年M月` 文案。
- 顶部增加“科目范围”信息块：默认展示“所有科目”，输入关键字后自动切换为“按关键字筛选”。
- 搜索框单独占一行，避免原先搜索输入框和按钮挤在同一层导致布局松散、不对齐。
- 右侧显示选项改为更紧凑的分段区域，3 个勾选项收纳到同一个 segmented 样式容器中，减少空白和视觉松散感。
- 本次继续把顶部工具栏相关圆角整体收窄，减少过大的圆角观感，让界面更接近财务软件的稳重风格。
- 右侧打印/导出按钮继续与显示设置分组展示，保留财务查询工具栏的操作层级。
- 页面默认期间为当前月份，切换期间后会自动刷新，也可点击“查询”按钮手动刷新。
- 按科目层级展示父级与子级，科目名称按层级缩进显示，展示顺序为父级在上、子级在下。
- 父级科目展示汇总值，子级科目继续展开明细，避免“父级 + 子级重复汇总”导致失真。
- 借贷余额按原始余额正负方向拆分显示：借方余额显示到借方列，贷方余额显示到贷方列，不再把贷方余额挤到借方。
- 第一层级通过父子关系动态计算，不再仅按编码长度硬判，避免层级展示错误。
- 合计行按根级父科目的展示列分别相加：期初借/贷、发生借/贷、期末借/贷各自独立汇总，不再先净额相抵后再拆分，避免合计失真。
- 页面父级高亮与合计行高亮改为跟随系统主题色变量，不再使用固定颜色。
- 展示科目编码、科目名称、期初余额、本期发生额、期末余额。
- 支持按科目编码/名称关键字过滤，并自动追加合计行。
- 已接入正式打印模板：点击打印时通过隐藏 iframe 输出 `print-templates/subject-balance.ts` 生成的打印文档，打印内容同步保留层级缩进。

## 入口
- 前端页面：`lmbill/apps/web-ele/src/views/erp/finance/ledger/subject-balance/index.vue`
- 路由页面：`/erp/finance/ledger/subject-balance`
- 组件名：`FinanceSubjectBalance`

## 数据来源/接口
- 会计科目：`getAllSubjectList`
- 科目期初/年初余额：`getSubjectOpeningList`
- 凭证主表与明细：`getVoucherPage` + `getVoucherDetails`
- 余额封装：`fetchSubjectBalanceRows`

## 关键字段
- 查询期间：`month`（格式 `YYYY-MM`）
- 期间展示：`monthLabel(month)` → `YYYY年M月`
- 关键字过滤：`keyword`
- 科目范围展示：`subjectScopeText`
- 科目编码：`subjectCode`
- 科目名称：`subjectName`
- 层级：`level`
- 末级标记：`isLeaf`
- 合计标记：`isTotal`

## 计算口径
- 单个科目先换算成“借为正、贷为负”的原始余额，再生成该科目的借方余额/贷方余额展示列。
- 父级科目金额 = 本科目自身金额 + 全部下级科目原始余额汇总。
- 页面普通行保留父子层级汇总逻辑，展示顺序改为先父后子。
- 页面合计行改为按根级科目的展示列分别累计，而不是先把所有根级净额相抵再拆分展示。
- 本期发生额仍按借方发生额、贷方发生额分别累计展示。

## 本次变更：展开所有级次
- 页面工具栏右侧新增 `展开所有级次` 勾选项，使用 Element Plus `ElCheckbox`。
- 页面保留接口返回的真实完整科目层级数据到 `rawTableData`，再通过计算属性 `tableData` 控制展示。
- 默认未勾选时仅展示一级科目和合计行；勾选后展示接口返回的全部科目级次。
- 打印、导出和底部显示条数均继续使用当前页面展示的 `tableData`，与勾选状态保持一致。
