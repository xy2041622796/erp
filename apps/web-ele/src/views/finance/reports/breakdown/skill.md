# 费用明细表页面

入口：`src/views/finance/reports/breakdown/index.vue`

页面能力：
- 展示费用类科目的凭证净发生额数据，用于财务报表中的费用明细查询、月份汇总、合计、打印和导出。
- 页面复用现有 `Page`、Element Plus 表单/表格组件、`useHorizontalWheelScroll` 横向滚动 hook，以及凭证主表/凭证明细 API 封装。
- 支持跨月、跨年查询，月份列由当前会计期间范围动态生成。
- 跨月查询按月份序列逐月调用 `getVoucherPage`，每个月先按本地月初/月末构造 `Date`，再用 `toISOString()` 传入 UTC ISO 格式 `voucherDateRange`，最后按凭证 rowid 去重组合成报表数据。

数据来源：
- 凭证主表：`getVoucherPage`，按每个会计月份转换出的 `voucherDateRange` 查询，并显式传入 `recycleState: 0` 排除回收站凭证。
- 凭证明细：`getVoucherDetailsByIds`，按凭证主表 rowid 批量拉取明细。

费用识别与归类规则：
- 费用科目范围：`5601/5602/5603/5801/6601/6602/6603/6801`。
- `5601/6601`：销售费用。
- `5602/6602`：管理费用。
- `5603/6603`：财务费用。
- `5801/6801`：所得税费用。
- 费用类型下拉不展示“其他费用”。

统计口径：
- 与明细账借方方向科目保持一致：费用金额 = `借方发生额 - 贷方发生额`。
- 费用金额由 `getExpenseOccurrenceAmount(detail)` 统一计算，避免“有借方取借方、否则取负贷方”的旧口径。
- 结转损益、期间结转、结转利润、期间反结转凭证整张排除，确保已结账后生成的结转类凭证不冲减原始费用。
- 不额外按 `is_reversed` 过滤，避免凭证范围与明细账不一致。
- 不按已过账、已结账状态过滤凭证；已结账期间内原始费用凭证仍应展示。

日期口径：
- 会计期间 `YYYY-MM` 先使用本地时间构造每个月查询边界：月初 `00:00:00` 到月末 `23:59:59`，再通过 `Date.toISOString()` 转成接口期望的 UTC ISO 字符串。
- 例如东八区选择 `2025-09` 时，月初边界由本地 `2025-09-01 00:00:00` 转为 `2025-08-31T16:00:00.000Z` 后传给接口。
- 例如选择 `2026-09` 到 `2026-10`，页面会分别按 9 月、10 月本地月初/月末生成 ISO 边界，再合并展示。

筛选与可见数据：
- 查询按钮重新触发 `loadData`，重新调用凭证接口查询当前会计期间数据。
- 费用类型在当前查询结果 `rows` 内即时过滤，产出统一的 `visibleRows`。
- 表格金额、合计、打印、导出均基于同一份 `visibleRows`，确保过滤后同步变化。
- 主表删除/回收站凭证通过 `getVoucherPage` 查询条件和页面二次过滤排除；明细删除/回收站行通过 `isActiveVoucherDetail` 二次过滤排除。

验证方式：
- 使用 `@vue/compiler-sfc` 对 `index.vue` 执行 SFC parse。
- 使用 `compileTemplate` 对模板编译。
