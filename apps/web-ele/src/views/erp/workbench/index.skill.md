# ERP 工作台在线咨询悬浮入口

## 页面/组件
- 页面文件：`src/views/erp/workbench/index.vue`
- 访问路径：`/erp/workbench`

## 页面能力
- 在 ERP 工作台右侧新增“在线咨询”悬浮组件。
- 悬浮组件包含竖向主入口“在线咨询”。
- 展开状态下显示“快速联系顾问”面板，包含“产品咨询”和“获取报价”两个操作入口。
- 支持点击侧边收起按钮将咨询面板收起到页面右侧，仅保留展开按钮。
- 收起后可再次点击按钮展开。

## 实现说明
- 使用 `onlineConsultCollapsed` 控制收起/展开状态。
- 使用 `.onlineConsultFloat.collapsed` 调整右侧定位实现收起效果。
- 当前两个操作入口为前端展示按钮，未绑定后端接口或外部跳转。

## 数据/接口
- 不依赖后端接口。
