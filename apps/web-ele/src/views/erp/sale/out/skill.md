# ERP / 销售 / 销售出库

审批绑定事件：`SALE_SHIPMENT`。

## 页面入口
- 路径：`apps/web-ele/src/views/erp/sale/out`
- 页面文件：`index.vue`
- 弹窗表单：`modules/form.vue`
- 出库明细子表：`modules/item-form.vue`
- 来源单选择：`modules/sale-order-select.vue`
- 配置文件：`data.ts`

## 当前页面能力
- 支持新增、编辑、查看销售出库单。
- 支持选择来源销售订单后，按源单明细中已分配的 `warehouse_id` 分组选择本次执行仓库。
- 支持不选择来源销售订单，直接选择执行仓库并新增产品明细后保存销售出库单。
- 无源单出库时，`order_id`、`order_no`、`customer_id`、`sale_user_id` 可以为空，`warehouse_id` 和明细产品、数量仍必须填写。
- 列表来源订单为空时显示“无源单”。

## 表单交互规则
- `order_no` 只读，可以通过来源单选择组件赋值，也可以留空表示无源单。
- `warehouse_id` 新增/编辑时可手工选择；选择源单后会由源单仓库分组覆盖为执行仓库；详情态或无字段权限时不可修改。
- `customer_id` 和 `sale_user_id` 新增/编辑时可手工选择，但不是必填；详情态或无字段权限时不可修改。
- 选择源单后，客户、销售人员、仓库和明细按原逻辑由销售订单带出。

## 金额字段权限
- 明细子表支持按明细项表字段权限动态显示金额列，权限字段以明细表 `product_price` 作为金额权限判断入口。
- 有明细表 `product_price` 字段可见/可编辑权限时，明细展示并允许维护 `product_price`、`tax_percent`，系统自动计算 `total_product_price`、`tax_price`、`total_price`。
- 无 `total_price` 字段可见权限时，明细隐藏产品金额、未税金额、税率、税额、含税合计等金额列。
- 无金额可见权限保存时，前端会从明细 `items` 中剔除 `product_price`、`total_product_price`、`tax_percent`、`tax_price`、`total_price`，避免覆盖历史金额。
- 新增弹窗会显式查询 `erp_sale_out_items` 明细项表读取一条权限模板；编辑/详情优先使用当前单据明细返回的 `lingma_sys_params`。

## 明细规则
- 无源单时可以点击产品清单列表上方右侧工具栏中的“新增产品”新增手工明细行，手工行允许选择产品。
- 有源单导入的明细行保留原行为：产品和仓库不可改，数量和备注可改，可删除行。
- 手工选择产品后自动带出产品名称、条码、单位、分类，并刷新当前仓库库存和总库存。
- 出库数量必须大于 0。
- 来源销售订单导入的明细行存在 `order_item_id` 时，本次出库数量不能大于 `total_count - out_count`。
- 手工新增产品行没有来源订单明细，不按销售订单剩余数量限制。

## 生成来源订单规则
- 选择来源销售订单时，会按源单明细 `warehouse_id` 分组选择本次执行仓库。
- `assertSaleOutCanGenerate` 会校验当前销售订单和当前仓库是否可继续生成销售出库单。
- 同一销售订单、同一仓库已存在待审批销售出库单（`status = 10`）时，禁止继续生成，并提示先审批或删除已有出库单。
- 待审批销售出库单只作为阻断条件，不计入销售订单已出库数量。

## 审批与库存规则
- 审批通过状态更新为 `20` 后，页面读取最新销售出库详情并调用 `saveDimensionResultByRulePayload('SALE_SHIPMENT', saleOutRow, null, { allowOverwrite: true })`，从模板库同步规则并生成维度结果。
- 无源单出库审批时只更新库存和库存流水，不回写销售订单。
- 有源单出库审批时，如果存在 `order_id` 和明细 `order_item_id`，继续按原逻辑回写销售订单出库数量与状态。
- 销售出库库存不足时保持现有接口行为，不在页面新增负库存拦截。

## 使用到的数据与接口
- 主表接口：`#/api/erp/sale/out`
- 来源销售订单接口：`#/api/erp/sale/order`
- 产品接口：`#/api/crm/product`
- 仓库接口：`#/api/erp/stock/warehouse`
- 库存接口：`#/api/erp/stock/stock`

## A5 打印规则
- 页面支持单张 A5 横向打印，公共模板位于 `src/views/erp/shared/print-templates`。
- 列表操作列提供“打印”入口，详情弹窗底部左侧提供打印入口。
- 打印前读取详情接口获取完整主表和明细，再生成独立 HTML 写入隐藏 iframe 打印。
- 销售订单、采购订单任意状态允许打印，并在打印件中显示当前状态。
- 销售出库单、采购入库单仅 `status = 20` 审核通过时正式打印；`status = 10` 只预览；`status = 30` 禁止打印。


## A5 打印调整补充
- 列表页不在操作列提供行内打印按钮，统一在列表右上角工具栏使用“打印选中”。
- 打印产品和仓库时优先展示名称；详情数据只有 ID 时，通过产品精简列表和仓库精简列表映射名称。
- 打印 iframe 使用 about:blank 写入 HTML，减少浏览器打印页脚显示业务页面地址的可能；浏览器驱动自带页眉页脚仍需在打印设置中关闭。


## 附件与备注布局规则
- 产品清单字段外层表单 label 置空，只保留产品清单子表区域自身标题，避免标题重复。
- 备注不再放在主表 schema 中，统一放到附件区域下面。
- 附件区域即使没有数据也必须渲染附件表格，使用表格 empty-text 展示“暂无附件”。
- 保存时备注从页面独立备注输入框同步到主表 remark 字段。

- 附件列表区域标题与上传按钮保持同一行，上传按钮放在列表右上角。

## 操作列按钮显示约定

- 表格操作列中的操作按钮不再通过 `ifShow`、`auth` 或操作列 `visible: !disabled` 隐藏。
- 不满足权限、状态或编辑态条件的操作按钮应继续显示，但通过 `disabled` 禁用。
- 原有禁用条件与显示条件合并时，使用“原 disabled 条件 OR 显示条件取反”，避免丢失已选中校验、单据状态校验等限制。
- 该约定适用于主列表操作列、子表产品清单操作列、附件表格操作列以及相关选择/记录列表操作列。
