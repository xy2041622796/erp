# ERP 期末检查工作台

## 页面入口

- 路径：`src/views/erp/settings/period-close/index.vue`
- 页面名称：`ErpPeriodClose`
- 业务定位：结账流程第 1 步，按截图实现期末检查卡片、生成凭证、下一步确认、自定义结转模板查看。

## 页面能力

- 展示 10 个期末检查项目：
  - 结转销售成本
  - 计提职工薪酬
  - 计提工资（工资模块）
  - 发放工资（工资模块）
  - 摊销待摊费用
  - 计提税金
  - 结转未交增值税
  - 计提所得税
  - 结转制造费用
  - 结转完工成本
- 每个卡片展示金额与“生成凭证”按钮。
- 支持选择结账日期并按期间重新加载检查结果。
- 支持点击“下一步”进入期末检查确认弹窗。
- 支持“自定义结转模板”查看当前结转模板 JSON。
- 保留反结账记录入口。


## 布局规范

- 期末检查内容区使用独立白底框 `period-check-frame`，宽度约 1280px，红色 1px 边框，整体居中展示。
- 顶部一行展示“第 1 步：期末检查”和橙色提示文案，右侧展示“自定义结转模板”按钮。
- 结账日期作为内部当前期间参数保留，不在卡片区展示，保持与截图布局一致。
- 卡片区固定 4 列，每个卡片宽 235px、高 140px，标题栏灰色渐变，左侧绿色图标，金额绿色下划线，右下角“生成凭证”按钮。
- 底部按钮居中展示“上一步 / 下一步 / 反结账”。

## 使用接口

- `getPeriodCheckPreview(params)`：加载期末检查项目、金额、借贷模板。
- `createPeriodCheckVoucher(request)`：按期末检查项目生成借贷平衡凭证。

## 数据来源

- 销售成本：`erp_sale_out`、`erp_sale_out_items`、`Bil_Product_Info`。
- 计提工资（工资模块）：卡片名称保持默认固定展示；按当前结转期间查询凭证维度表 `Bil_Dimension_Set` / `Bil_Dimension_Detail`，仅统计 `is_voucher_required = 1` 且 `voucher_no` 为空、业务日期属于当前月份、事件/分类/摘要/维度明细包含工资、薪酬、薪资、SALARY、WAGE、PAYROLL 的维度结果；有数据时展示未结转金额，并在说明中展示检测到的维度来源，没有数据时金额展示 0。
- 工资、税金、待摊、制造费用、完工成本其他项目：作为模板入口保留，后续接入工资、报销、生产、税务等业务表。
- 凭证写入：`Bil_Voucher_Main`、`Bil_Voucher_Detail`，通过现有凭证 API `createVoucher`。

## 请求规范

- 期末检查数据读取统一通过 `DataTable.getQueryParam('Table', table.Filter, null, null, pageSize, 1)` 生成 `DataOperation/GetData` 请求体。
- `PageParam` 使用 `{ index, size }`，避免手写 `{ page, index }` 导致后端请求项解析失败。
- 销售出库明细、产品档案、凭证维度子表不向后端发送数组型 `in` 条件；先按账套和删除标记取数，再在前端按主表 ID 集合过滤，避免 GetData 对数组请求项兼容性问题。

## 账平规则

- 当前生成凭证时使用一借一贷，借方金额等于贷方金额。
- 金额为 0 的项目禁止生成凭证。
- 缺少借贷科目模板的项目禁止生成凭证。

## 后续扩展

- 工资维度写入规则应在工资结算/审批完成时同步写入 `Bil_Dimension_Set` / `Bil_Dimension_Detail`，并保证 `period` 为工资所属月份、`voucher_no` 在生成凭证后回写。
- 报销/费用模块接入费用结转模板后，扩展待摊费用、税金等项目。
- 生产模块接入制造费用归集表和完工成本表后，自动计算结转制造费用、结转完工成本。
