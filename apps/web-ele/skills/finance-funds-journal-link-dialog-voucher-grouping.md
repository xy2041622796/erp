# 资金日记账关联凭证弹窗：主行 + 明细行展示

## 入口页面
- 银行日记账：`src/views/finance/funds/bankjournal/index.vue`
- 现金日记账：`src/views/finance/funds/cashday/index.vue`

## 能力说明
- 关联凭证弹窗不再使用展开列。
- 表格按“凭证主行 + 凭证明细行”的平铺结构展示：
  - 主行：展示凭证日期、凭证字号、汇总摘要、借贷合计、制单人，并提供“关联”操作。
  - 明细行：紧跟在对应主行后面，展示该分录的摘要、科目、借方金额、贷方金额。
- 一张凭证只生成一个主行，下面跟随该凭证的所有明细行，通常为两行借贷分录。
- 只有主行可以点击“关联”，明细行不提供关联按钮。

## 复用接口
- `getVoucherPage`：查询凭证主表列表。
- `getVoucherDetails`：查询每张凭证的明细，并平铺到主行后面。

## 展示规则
- 凭证字号列：主行显示凭证字号，例如 `记1`；明细行显示“明细”。
- 摘要列：主行显示明细摘要去重后的合并结果；明细行显示该条分录摘要。
- 科目列：仅明细行显示 `account_code account_name`。
- 金额列：主行显示凭证借贷合计；明细行显示该分录借贷金额。

## 风险点
- 弹窗加载时会按凭证主表逐张读取明细，凭证数量较大时接口请求数量会增加。
