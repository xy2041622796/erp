# 固定资产新增/编辑：月折旧额按剩余可折旧金额分摊

- 页面入口：财务系统 / 固定资产 / 资产管理 / 新增资产或编辑资产弹窗。
- 页面文件：`src/views/finance/assets/manage/modules/form.vue`。
- 相关接口：复用 `#/api/erp/finance/assets/manage` 中的 `saveAsset`、`buildNextAssetCode`；复用资产类别、科目、供应商、部门等已有接口。
- 核心能力：资产数据区录入资产原值、残值率、累计折旧、预计使用月份、已折旧月份后，自动计算预计残值、净值、剩余使用月份、月摊销额/月折旧额。
- 当前公式：
  - 预计净残值 = 资产原值 × 残值率
  - 净值 = 资产原值 - 累计折旧
  - 剩余使用月份 = 预计使用月份 - 已折旧月份
  - 月折旧额 =（净值 - 预计净残值）÷ 剩余使用月份
- 注意事项：`residual_rate` 支持百分数输入，计算中大于 1 时按百分比换算；金额继续使用 `decimal-money` 工具处理精度。
