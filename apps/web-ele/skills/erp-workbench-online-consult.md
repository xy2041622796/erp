# ERP 工作台在线咨询悬浮入口

## 入口
- 页面：`src/views/erp/workbench/index.vue`
- 组件区域：模板底部的 `onlineConsultFloat`。

## 能力
- 在 ERP 工作台右侧固定展示“在线咨询”竖向按钮。
- 鼠标 hover 或键盘 focus 到悬浮入口时展示咨询面板。
- 咨询面板统一在按钮同一侧垂直展开，按钮与面板垂直居中对齐，避免左右交替或上下错位。
- 面板提供“产品咨询”和“获取报价”两个快捷操作按钮。

## 数据与接口
- 当前两个快捷操作为前端展示按钮，暂未绑定后端线索接口。
- 页面已有导航、租户、天气、权限菜单等数据逻辑保持不变。

## 交互约束
- 不再通过点击箭头折叠/展开。
- 面板默认隐藏，仅通过 CSS `:hover` 与 `:focus-within` 显示。
- 移动端继承固定悬浮样式。
