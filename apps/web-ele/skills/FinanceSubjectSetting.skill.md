# FinanceSubjectSetting（会计科目设置）页面能力

## 入口
- 路由：`/erp/finance/settings/project`
- 组件：`lmbill/apps/web-ele/src/views/erp/finance/settings/project/index.vue`
- 表单弹窗：`lmbill/apps/web-ele/src/views/erp/finance/settings/project/modules/form.vue`

## 主要能力
- 通过 Tabs 按科目类别切换（资产/负债/权益/成本/损益）。
- 树形展示会计科目（科目编码/名称/余额方向/辅助核算/状态）。
- 新增根科目/新增子科目/编辑/查看/删除（软删）。
- 科目编码在新增子科目时支持根据父级自动代入，并按统一层级规则校验。
- 上级会计科目支持下拉选择，数据来源为当前系统现存科目。
- 新增子级科目时，无论父级科目下是否已有凭证明细，都会先弹出统一确认框；用户点击“确定”后才继续创建子级科目。
- 当父级科目下已经存在凭证明细时，新增子级科目成功后会将该父级科目下全部凭证明细批量转移到新子级科目。
- 删除下级科目时，会先执行预检查并弹出提醒；如果该下级是父级下最后一个子级，则删除后会自动把当前科目凭证分录以及凭证里对应的科目归属一起转移到父级，并把父级科目转成末级科目。
- 科目列表、上级科目下拉、父级直接子级列表统一按 `subject_number` 升序返回；当编码相同或数据库返回顺序不稳定时，再以 `rowid` 作为兜底排序，避免同步新增后显示顺序错乱。

## 下拉数据来源
- 上级会计科目：通过 `getAllSubjectList()` 异步请求 `Bil_Subject_Info` 表后，映射为 `label/value` 绑定到 Select。
- 科目类别：通过 `getSubjectTypeOptions()` 异步加载后绑定到 Select。
- 表单弹窗打开时会先加载这两组 options，再回填已有值。
- 当已选择上级科目时，科目类别自动锁定为父级所属类别。

## 编码自动代入与校验规则
- 编码层级规则改为：`4-3-2-2`。
- 顶级科目：
  - 必须是纯数字。
  - 长度固定为 `4` 位。
  - 必须以当前科目类别值开头：
    - 资产：`1xxx`
    - 负债：`2xxx`
    - 权益：`3xxx`
    - 成本：`4xxx`
    - 损益：`5xxx`
- 子科目自动代入：
  - 父级长度 `4` 位时，新增下级自动补 `3` 位，例如：`1001 -> 1001001`
  - 父级长度 `7` 位时，新增下级自动补 `2` 位，例如：`1001001 -> 100100101`
  - 父级长度 `9` 位时，新增下级自动补 `2` 位，例如：`100100101 -> 10010010101`
  - 父级达到 `11` 位时，视为末级，不允许继续新增下级。
- 前后端统一按上述规则做保存校验，避免页面绕过或非法提交。

## 新增子级与凭证转移说明
- 仅在“新增子级科目”时触发，不影响新增顶级科目或编辑科目。
- 保存前会根据父级科目编码查询 `Bil_Voucher_Detail.account_code`。
- 无论是否存在数据，都会弹出统一确认框，文案为：
  - `当前操作将新增子级科目，并在存在凭证时自动转移到新科目，是否继续`
- 点击“确定”：继续保存新子级。
- 点击“取消”：终止本次保存，不创建新子级。
- 若存在凭证明细：新增成功后批量把父级科目下全部凭证明细的 `account_code/account_name` 改为新子级科目。
- 若不存在凭证明细：仅完成新增，不做凭证迁移。
- 转移只更新凭证明细挂靠科目，不修改借贷金额、摘要、凭证主表等字段。

## 删除子级与父级回收说明
- 删除时不再使用固定文案，而是先调用预检查逻辑动态生成提醒。
- 若删除的是普通下级科目：提示用户确认删除。
- 若当前科目下存在凭证明细，但删除后不会转移：会明确提醒用户当前科目下有凭证。
- 若删除的是父级下最后一个子级：
  - 系统会先检查该科目是否存在凭证明细；
  - 若存在，则删除成功后自动把这些凭证分录及凭证中对应的科目归属一起转移到父级科目；
  - 无论是否存在凭证，父级科目都会被自动更新为末级科目（`is_leaf_subject=1`）。
- 当前项目中，凭证页、总账、明细账等读取的科目归属核心来源于 `Bil_Voucher_Detail.account_code/account_name`；因此删除迁移时同步更新这两个字段后，凭证里的科目显示也会一并切换到父级。
- 删除流程顺序：预检查提醒 -> 用户确认 -> 必要时转移凭证分录及凭证中的科目归属 -> 必要时父级转末级 -> 删除当前科目。

## 交互说明
- 选择上级科目后，系统会自动带出：上级科目名称、科目类别、余额方向。
- 同时根据当前父级现存子科目，自动计算下一个可用编号。
- 自动带入后的编号仍可手工调整，但必须满足 `4-3-2-2` 规则。

## 校验位置
- 前端表单保存前校验与确认弹窗：`modules/form.vue`
- 删除确认与删除预检查：`index.vue`
- 保存接口校验、删除预检查、凭证分录及凭证科目归属批量迁移、父级末级回收：`src/api/erp/finance/settings/project/index.ts`
- 采用前后端双重校验，避免绕过页面直接提交非法编码或删除异常数据。

## 数据/接口
- 科目主数据表：`Bil_Subject_Info`
- 凭证明细表：`Bil_Voucher_Detail`
- 查询列表：`getSubjectList`（树形展示，统一按科目编码升序）
- 查询全部现存科目：`getAllSubjectList`（上级科目下拉，统一按科目编码升序）
- 查询科目类别 options：`getSubjectTypeOptions`
- 根据主键查询单个科目：`getSubject`
- 根据编码查询单个科目：`getSubjectByNumber`
- 查询父级直接子级：`getChildSubjectListByParentNumber`（统一按科目编码升序）
- 查询删除影响预览：`getDeleteSubjectEffect`
- 查询父级科目凭证明细数量：`countVoucherDetailsByAccountCode`
- 批量转移凭证明细到新科目/父级科目：`moveVoucherDetailsToSubject`
- 新增：`createSubject`
- 编辑：`updateSubject`
- 删除：`deleteSubject`（带预检查后的删除流程，内部最终软删）
