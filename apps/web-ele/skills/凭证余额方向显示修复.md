# 凭证余额方向显示修复

## 本次改动
- 修复新增凭证页面中“会计科目”下方余额提示未按当前业务财务逻辑联动的问题。
- 新增余额方向识别逻辑，支持从科目数据中读取 `balance_direction / balanceDirection / direction / dc`。
- 将科目方向固定为会计科目配置的借方或贷方，不再因计算结果切换方向文案。
- 将科目原余额按该方向下的基数处理后，再结合当前录入金额联动计算。
- 借方科目按 `原余额 + 借方 - 贷方` 计算。
- 贷方科目按 `原余额 + 贷方 - 借方` 计算。
- 展示格式为 `±金额（借）` 或 `±金额（贷）`，其中借/贷文案固定跟随科目方向。

## 修改文件
- `src/views/erp/finance/Voucher/modules/VoucherEntryTable.vue`

## 验证步骤
1. 进入财务凭证新增页。
2. 选择借方方向科目，输入借方金额，确认余额增加且方向仍显示借。
3. 选择借方方向科目，输入贷方金额，确认余额减少且方向仍显示借。
4. 选择贷方方向科目，输入贷方金额，确认余额增加且方向仍显示贷。
5. 选择贷方方向科目，输入借方金额，确认余额减少且方向仍显示贷。

## 注意事项
- 本改动只影响前端展示，不改变后端余额值存储。
- 当前业务规则是“方向固定，增减互斥”；若后续业务口径恢复为可翻转方向，需要重新调整展示逻辑。
