# 固定资产原值调整：生成凭证规则修正

- 页面入口：财务系统 / 固定资产 / 资产管理 / 资产列表 / 变更 / 原值调整，以及资产管理 / 变更记录及生成凭证。
- 相关文件：
  - `src/views/finance/assets/manage/modules/assetChangeVoucher.ts`
  - `src/views/finance/assets/manage/change-voucher/index.vue`
- 核心能力：原值调整生成凭证时，不再使用资产卡片上的 `disposal_subject_code/disposal_subject_name` 作为对方科目，避免误带入银行存款等错误科目。
- 当前规则：
  - 原值调增：借记资产科目，贷记固定资产清理/资产处置损益方向科目。
  - 原值调减：借记固定资产清理/资产处置损益方向科目，贷记资产科目。
  - 对方科目优先匹配 `1606 固定资产清理`，兼容 `资产处置损益` 关键字。
- 摘要规则：凭证分录摘要按 `变更类型_使用部门 资产名称/资产编号` 生成，例如 `原值调整_财务软件使用权ZC0002`，借贷两行保持一致。
- 影响范围：从原值调整保存后直接跳转生成凭证、以及从“变更记录及生成凭证”批量/单条生成凭证。
