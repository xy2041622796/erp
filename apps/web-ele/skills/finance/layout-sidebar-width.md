# 财务系统左侧导航宽度

## 页面/入口
- 全局布局配置：`apps/web-ele/src/preferences.ts`
- 影响入口：财务系统左侧菜单，包含资金、资产、账簿、报表、设置等模块导航。

## 能力说明
- 通过 `overridesPreferences.sidebar.width` 控制左侧导航展开态宽度。
- 当前宽度为 `150`，用于减少“银行日记账”等较长菜单名称被省略的情况。
- 折叠态宽度仍复用现有配置：`mixedWidth: 52`、`collapseWidth: 40`、`extraCollapsedWidth: 40`。

## 使用的数据或接口
- 不调用业务接口。
- 不涉及后端数据结构，仅影响前端布局展示。

## 注意事项
- 修改后如页面未立即生效，需要清空前端缓存或重新登录刷新偏好配置。
- 后续若继续调整菜单宽度，优先修改 `preferences.ts` 中已有 `sidebar` 配置，不新增布局体系。
