# HrOrganOrgChartPage Skill

## 页面入口
- `src/views/erp/HumanResources/organ/org-chart/index.vue`

## 能力
- 图形化组织架构图展示
- 左侧组织目录定位节点
- 查看当前节点上下级、岗位、人员规模
- 输出组织架构层级信息

## 数据来源
- `Base_DepartInfo`
- `Base_JobInfo`
- `view_user_dj`

## 依赖组件
- `OrganizationTreePanel.vue`
- `OrganizationChartCanvas.vue`
- `HrAnalyticsPanel.vue`
