# period

- 页面入口：`/erp/finance/period`
- 页面名称：期末处理
- 页面形态：单一路由分步页
- 步骤一：期末检查。按真实业务表预检本期需自动生成的业务凭证，当前已接入销售出库、工资表；未接入项目会明确显示为“未接入”，不再使用 mock 金额。
- 步骤二：期间结转。基于总账已过账凭证汇总本期收入、费用，生成“期间结转”凭证。
- 预检数据来源：`src/api/erp/finance/period-check/index.ts`
- 期间结转数据来源：`src/api/erp/finance/period/index.ts`
- 说明：本页不新增额外路由，通过步骤切换完成月末处理流程。
