# 资金日记账生成凭证：按现有科目模糊匹配

## 入口页面
- 银行日记账：`src/views/finance/funds/bankjournal/index.vue`
- 现金日记账制证页：`src/views/finance/funds/cashday/voucher-create.vue`

## 能力说明
- 生成凭证不再依赖收支类别绑定科目。
- 生成前读取现有科目表：`getAllSubjectList({ lingma_sys_is_delete: 0 })`。
- 资金方科目按当前账户名称、账户编码、账户类型及关键词模糊匹配现有末级科目。
  - 银行日记账优先匹配：银行存款、其他货币资金、货币资金等资产类末级科目。
  - 现金日记账优先匹配：库存现金、现金等资产类末级科目。
- 对方科目按收支类别名称、摘要、往来单位、收入/支出方向关键词模糊匹配现有末级科目。
- 不再硬编码 `6001` 或 `6602`。

## 生成规则
- 收入：借记模糊匹配到的资金方科目，贷记模糊匹配到的对方科目。
- 支出：借记模糊匹配到的对方科目，贷记模糊匹配到的资金方科目。
- 若无法从现有科目表模糊匹配出末级科目，则阻止生成并提示检查科目名称或类别名称。

## 数据来源
- 资金账户：银行日记账使用 `fetchBankAccounts`，范围包含“银行存款、其他货币资金”；现金日记账使用 `fetchCashAccounts`。
- 收支类别：银行日记账和现金日记账均可展示类别名称；生成凭证时类别名称仅作为模糊匹配文本，不要求绑定科目。
- 科目表：`src/api/erp/finance/settings/project` 的 `getAllSubjectList`。

## 风险点
- 模糊匹配依赖科目名称、类别名称、摘要文本的一致性；名称过于笼统时可能匹配不到或匹配不准确。
- 只使用现有启用、未删除、末级科目生成凭证。
