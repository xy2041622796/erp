# 凭证余额方向显示修复

## 问题现象
新增凭证页面中，输入会计科目后，科目下方余额提示只显示数值，不区分借方余额还是贷方余额。
后续在借方或贷方录入金额时，余额提示也不会跟随当前分录金额变化。
另外，方向文案此前错误地允许跟着计算结果切换，和当前业务规则不一致。

## 根因
`VoucherEntryTable.vue` 里此前把“余额方向是否切换”也纳入了运算结果判断。
但当前业务口径是：
- 科目的借贷方向由科目设置决定，方向本身不变；
- 只是在该固定方向下，借方和贷方对余额的增减规则互斥：
  - 借方科目：借方 +，贷方 -
  - 贷方科目：贷方 +，借方 -
因此本次问题不是“方向翻转”，而是“固定方向下的加减法规则”。

## 修复内容
1. 在 `VoucherEntryTable.vue` 中保留科目方向解析逻辑，兼容 `balance_direction / balanceDirection / direction / dc`。
2. 将会计科目原始余额按绝对值作为该科目方向下的基数余额。
3. 固定方向展示，不再根据运算结果切换借/贷文案。
4. 按互斥规则联动计算余额：
   - 借方科目：`原余额 + 借方金额 - 贷方金额`
   - 贷方科目：`原余额 + 贷方金额 - 借方金额`
5. 展示格式改为：
   - 科目方向固定为借方时：`±金额（借）`
   - 科目方向固定为贷方时：`±金额（贷）`
6. 只有在方向字段缺失时，才使用原有兜底逻辑按正负推断借/贷。

## 影响范围
- 文件：`lmbill/apps/web-ele/src/views/erp/finance/Voucher/modules/VoucherEntryTable.vue`
- 页面：财务 → 凭证 → 新增凭证 / 编辑凭证

## 验证方法
1. 打开新增凭证页面。
2. 选择借方方向科目，输入借方金额，确认余额增加且文案始终显示借。
3. 对同一借方方向科目输入贷方金额，确认余额减少，但文案仍显示借。
4. 选择贷方方向科目，输入贷方金额，确认余额增加且文案始终显示贷。
5. 对同一贷方方向科目输入借方金额，确认余额减少，但文案仍显示贷。

## 备注
本次修复仅调整前端余额提示展示逻辑，不修改凭证保存结构和后端数据。
