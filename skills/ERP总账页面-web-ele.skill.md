# ERP 总账页面 web-ele

- 页面入口：`apps/web-ele/src/views/finance/ledger/general/index.vue`
- 数据入口：`apps/web-ele/src/api/erp/finance/ledger/general.ts`
- 列定义入口：`apps/web-ele/src/views/finance/ledger/general/data.ts`
- 页面能力：展示总账数据，按期间范围统计科目的期初余额、本期合计、本年累计与余额；支持科目关键字搜索、查询、打印、导入与导出。
- 工具栏布局：查询条件在表格容器内部顶部，与科目余额表、科目汇总表保持一致；表格顶部展示查询期间、科目搜索、只展示顶级、查询、打印、导入、导出按钮。
- 查询期间：使用 Element Plus `ElDatePicker` 的 `monthrange`，通过一个组件选择开始月份到结束月份，字段绑定 `periodRange`，提交参数为 `periodStart` 与 `periodEnd`。
- 科目搜索：使用 Element Plus `ElInput` 绑定 `keyword`，输入框固定为 220px 宽，筛选项不再占满剩余工具栏空间，避免在宽屏下搜索框过宽。
- 顶级/父级汇总：`fetchGeneralLedgerRows` 先加载当前账套全部科目，用凭证发生额与科目期初余额向上汇总到父级/顶级科目；父级/顶级科目行展示本级及下级合计后的本期借方、本期贷方、余额方向和余额，摘要列保持为空，不显示“汇总”文字。
- 只展示顶级：页面使用 `onlyShowTopLevel` 控制右上角 `ElCheckbox`。勾选后，表格只展示科目编码长度小于等于 4 的顶级科目，例如 1001、1002，不展示其下级科目；但每个顶级科目仍保留展开子行，展示 `期初余额`、`本期合计`、`本年累计` 三行。
- 展开明细：未勾选“只展示顶级”时，每个科目保留展开子行，展示该科目的 `期初余额`、`本期合计`、`本年累计` 三行；父级科目的三行展示的是父级及其下级汇总后的金额。
- 搜索逻辑：科目搜索按编码/名称匹配，匹配到下级科目时会保留其父级/顶级科目，避免搜索后丢失汇总层级。
- 摘要展示：总账摘要列不使用溢出省略，页面通过 `general-ledger-summary-cell` 和深度样式让摘要完整换行展示，行高随内容撑开；其他列仍可使用 Element Plus 的溢出提示。
- 数据逻辑：`fetchGeneralLedgerRows` 兼容原 `month` 参数，同时支持 `periodStart/periodEnd`；年初到结束月份用于计算累计，开始月份到结束月份用于计算本期发生额。
- 打印能力：通过 `buildGeneralLedgerPrintHtml` 生成总账打印 HTML，并使用隐藏 iframe 调起浏览器打印；打印使用当前页面展示数据，勾选“只展示顶级”时打印顶级科目及其三行汇总明细。
- 导出能力：使用 `exceljs` 在前端生成 `.xlsx`，导出文件名包含期间与当前账套名称；导出内容来自当前页面展示数据，工作簿包含“总账”和“导入说明”两个 sheet，并在说明中标明数据来自当前选中账套。
- 导出表头：导出的“总账”sheet 第 1 行合并 A1:H1，标题“总账”加粗、16px、垂直/水平居中，并设置行高；第 2 行账套/期间信息与第 3 行字段表头也居中显示。
- 导入能力：使用隐藏文件输入选择 `.xlsx/.xls`，实际解析采用 `exceljs`，旧版 `.xls` 会提示先另存为 `.xlsx`；导入前必须存在 `accountSetStore.currentId`，确认框会展示当前账套名称。
- 导入写入规则：总账导入只读取摘要为 `本期合计` 的行，自动跳过科目汇总根行、`期初余额` 与 `本年累计`；导入前校验借贷合计相等，不平衡时不写入。
- 导入目标账套：导入通过 `createVoucher` 生成一张 `总账导入` 凭证，凭证主表与明细表使用财务当前账套 DataTable 封装自动写入 `account_set_id`，因此导入数据进入当前选中账套。
