# 现金流量表页面

## 页面入口
- 路由标题：现金流量表
- 页面文件：`apps/web-ele/src/views/finance/cwhs/reports/cash-flow/index.vue`
- 报表 API：`apps/web-ele/src/api/erp/finance/reports/index.ts` 中的 `fetchCashFlowReport`

## 页面能力
- 支持按月份查看现金流量表。
- 支持按季度查看本季金额。
- 支持切换“上年累计金额”。
- 支持打印现金流量表。

## 当前计算口径
现金流量表采用“科目余额/发生额倒推法”，不再使用原先的“现金分录 + 摘要关键词归类法”。

展示口径按上传的 Excel 小企业现金流量表 22 行：
- 经营活动：行次 1-7
- 投资活动：行次 8-13
- 筹资活动：行次 14-19
- 现金净增加额、期初现金余额、期末现金余额：行次 20-22

核心数据来源：
- 科目列表：`getAllSubjectList`
- 科目期初：`getSubjectOpeningList`
- 凭证主表：`getVoucherPage`
- 凭证明细：`getVoucherDetailsBatch`

核心字段：
- `year_beginning_balance`：年初余额
- `beginning_balance`：建账/期初余额兜底
- `debit_amount`：借方发生额
- `credit_amount`：贷方发生额
- `balance_direction`：余额方向

## 主要公式
- 经营活动净额 = 销售收现 + 其他经营收现 - 采购付现 - 职工付现 - 税费付现 - 其他经营付现
- 投资活动净额 = 收回投资收现 + 投资收益收现 + 处置长期资产收现 - 投资支付现金 - 购建长期资产付现
- 筹资活动净额 = 取得借款收现 + 吸收投资者投资收现 - 偿还借款本金 - 偿还借款利息 - 分配利润
- 现金净增加额 = 经营活动净额 + 投资活动净额 + 筹资活动净额
- 期末现金余额 = 期初现金余额 + 现金净增加额

## 核验规则
- 现金净增加额必须与现金类科目余额变动一致。
- 为避免双算，财务费用/利息类金额计入筹资活动“偿还借款利息支付的现金”后，不再计入经营活动“支付其他与经营活动有关的现金”。
- 若倒推项目因科目编码口径不全产生差额，系统会把差额兜底归入“收到/支付其他与经营活动有关的现金”，保证行次 20、22 与现金类科目余额闭合。

## 注意事项
- 当前倒推法按常见小企业科目编码前缀聚合。若账套存在自定义科目编码，需要同步扩展 `buildCashFlowByBalanceMethod` 中的科目前缀配置。
- 当前 skill 描述对应本次现金流量表页面与报表 API 的实现，可用于后续编排或继续优化。
